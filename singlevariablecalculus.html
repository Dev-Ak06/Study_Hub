1. Introduction

Single variable calculus studies how a function changes and how its values can be approximated using derivatives. In this module, we study Rolle's theorem, Mean Value Theorems, Taylor's theorem and Taylor series.

2. Rolle's Theorem

Statement

Let f(x) be a function satisfying these three conditions on the interval [a,b]:

  1. f(x) is continuous on [a,b].
  2. f(x) is differentiable on (a,b).
  3. f(a) = f(b).

Then there exists at least one number c in (a,b) such that:

f'(c) = 0

Meaning: At least one point inside the interval has a horizontal tangent.

Solved Example 1

Question:

Verify Rolle's theorem for f(x) = x² - 4x + 3 on [1,3] and find c.

Step 1: Check continuity.

Since f(x) is a polynomial, it is continuous on [1,3].

Step 2: Check differentiability.

A polynomial is differentiable everywhere, so it is differentiable on (1,3).

Step 3: Check endpoint values.

f(1) = 1 - 4 + 3 = 0

f(3) = 9 - 12 + 3 = 0

Therefore, f(1) = f(3).

Step 4: Differentiate.

f'(x) = 2x - 4

According to Rolle's theorem:

2c - 4 = 0

2c = 4

c = 2

Since 2 belongs to (1,3), Rolle's theorem is verified.

Solved Example 2

Question:

Verify Rolle's theorem for f(x) = x² - 9 on [-3,3].

Solution:

The function is a polynomial, so it is continuous and differentiable on the required intervals.

f(-3) = 9 - 9 = 0

f(3) = 9 - 9 = 0

Hence, f(-3) = f(3).

f'(x) = 2x

Set f'(c) = 0:

2c = 0

c = 0

3. Lagrange's Mean Value Theorem (LMVT)

Statement

If f(x) is continuous on [a,b] and differentiable on (a,b), then there exists c in (a,b) such that:

f'(c) = [f(b) - f(a)] / (b - a)

The derivative at c equals the average rate of change over the interval.

Solved Example 1

Verify LMVT for f(x) = x² on [1,3].

Step 1:

f(x) = x² is continuous and differentiable everywhere.

Step 2: Apply the theorem.

f'(c) = [f(3) - f(1)] / (3 - 1)

f(3) = 9 and f(1) = 1.

f'(c) = (9 - 1) / 2 = 4

Now differentiate:

f'(x) = 2x

Therefore:

2c = 4

c = 2

Since 2 is in (1,3), LMVT is verified.

Solved Example 2

Find c for f(x) = x³ on [0,2] using LMVT.

f(2) = 8 and f(0) = 0.

f'(c) = (8 - 0) / (2 - 0) = 4

Since f'(x) = 3x²:

3c² = 4

c² = 4/3

c = 2/√3

The positive value lies inside (0,2), so the theorem is verified.

4. Cauchy's Mean Value Theorem (CMVT)

Statement

If f and g are continuous on [a,b] and differentiable on (a,b), then there exists c in (a,b) such that:

[f(b)-f(a)]g'(c) = [g(b)-g(a)]f'(c)

When the denominators are nonzero, this can also be written as:

f'(c) / g'(c) = [f(b)-f(a)] / [g(b)-g(a)]

Solved Example

Verify CMVT for f(x) = x² and g(x) = x on [1,3].

Both functions are continuous and differentiable.

f(3) - f(1) = 9 - 1 = 8

g(3) - g(1) = 3 - 1 = 2

f'(x) = 2x and g'(x) = 1

Using CMVT:

8 × 1 = 2 × 2c

8 = 4c

c = 2

Since 2 is in (1,3), CMVT is verified.

5. Taylor's Theorem

Taylor's theorem represents a sufficiently smooth function using a polynomial and a remainder term.

f(x) = f(a) + f'(a)(x-a) + f''(a)(x-a)²/2! + ... + f⁽ⁿ⁾(a)(x-a)ⁿ/n! + Rₙ

Here, Rₙ represents the remainder after the nth-degree polynomial. The theorem's precise assumptions depend on the form of the remainder used.

Lagrange Form of the Remainder

Rₙ = f⁽ⁿ⁺¹⁾(c)(x-a)ⁿ⁺¹/(n+1)!

Here, c lies between a and x, under the conditions required by Taylor's theorem.

Solved Example

Expand f(x) = x² + 3x + 2 about a = 1 using Taylor's theorem.

Step 1:

f(1) = 1 + 3 + 2 = 6

Step 2:

f'(x) = 2x + 3

f'(1) = 5

Step 3:

f''(x) = 2

f''(1) = 2

Since the function is quadratic, higher derivatives are zero.

f(x) = 6 + 5(x-1) + (2/2!)(x-1)²

Final answer:

f(x) = 6 + 5(x-1) + (x-1)²

6. Maclaurin's Theorem

Maclaurin's theorem is a special case of Taylor's theorem in which the expansion point is a = 0.

f(x) = f(0) + f'(0)x + f''(0)x²/2! + f'''(0)x³/3! + ...

A remainder term is needed when expressing a finite Taylor polynomial as an exact equality for a general function.

Solved Example

Find the Maclaurin expansion of eˣ up to x³.

All derivatives of eˣ are eˣ, so at x = 0, every derivative equals 1.

eˣ = 1 + x + x²/2! + x³/3! + ...

Up to the third-degree term:

eˣ ≈ 1 + x + x²/2 + x³/6

This is a polynomial approximation; the omitted terms form the remainder.

7. Important Taylor and Maclaurin Series

eˣ = 1 + x + x²/2! + x³/3! + ...
sin x = x - x³/3! + x⁵/5! - ...
cos x = 1 - x²/2! + x⁴/4! - ...
1/(1-x) = 1 + x + x² + x³ + ...

Note: These series have convergence conditions. For example, the geometric series for 1/(1-x) converges when |x| < 1.

8. Common Exam Mistakes

  • Forgetting to check all three conditions of Rolle's theorem.
  • Using a closed interval instead of the open interval when checking the value of c.
  • Forgetting the denominator (b-a) in LMVT.
  • Confusing Taylor expansion about a general point a with Maclaurin expansion about zero.
  • Writing a finite polynomial approximation as an exact equality without accounting for the remainder.
