Module 1: Linear Algebra

Linear Algebra is an important branch of mathematics that deals with matrices, systems of linear equations, vector-like quantities, eigenvalues and eigenvectors. It is widely used in computer science, machine learning, computer graphics and engineering.

1. Echelon Form and Canonical Form

1.1 Elementary Row Operations

Elementary row operations are operations performed on the rows of a matrix to simplify it. They are useful for finding the rank of a matrix and solving systems of linear equations.

  • Row interchange: Interchange two rows, such as R₁ ↔ R₂.
  • Row scaling: Multiply a row by a non-zero constant, R₁ → kR₁.
  • Row replacement: Add a multiple of one row to another, such as R₂ → R₂ − 2R₁.

1.2 Row Echelon Form (REF)

A matrix is in row echelon form when:

  • All zero rows, if present, are at the bottom.
  • The first non-zero entry of each non-zero row is to the right of the first non-zero entry in the row above it.
  • All entries below each leading entry are zero.
Example of REF:

[ 1  2  3 ]
[ 0  1  4 ]
[ 0  0  2 ]

1.3 Reduced Row Echelon Form

In reduced row echelon form (RREF), each leading entry is 1 and is the only non-zero entry in its column.

Example of RREF:

[ 1  0  3 ]
[ 0  1  4 ]
[ 0  0  0 ]

1.4 Canonical or Normal Form

In the context of matrix rank, canonical form commonly refers to reducing a matrix using elementary row and column operations to a block form containing an identity matrix followed by zeros.

Canonical form of a rank-r matrix:

[ Iᵣ  0 ]
[ 0   0 ]

Here, Iᵣ is an identity matrix of order r. The exact meaning of canonical form can vary by textbook, so follow the convention used in your class notes.

Solved Example 1: Convert a matrix into echelon form

Given:
A = [ 1  2  3 ]
   [ 2  4  7 ]
   [ 1  1  2 ]

Step 1: Apply R₂ → R₂ − 2R₁.

[ 1  2  3 ]
[ 0  0  1 ]
[ 1  1  2 ]

Step 2: Apply R₃ → R₃ − R₁.

[ 1  2  3 ]
[ 0  0  1 ]
[ 0  -1  -1 ]

Step 3: Interchange R₂ and R₃.

[ 1  2  3 ]
[ 0  -1  -1 ]
[ 0  0  1 ]

This is an echelon form because the leading non-zero entries move to the right as we move down the rows.

2. Inverse of a Matrix

The inverse of a square matrix A is a matrix A⁻¹ such that multiplying A by A⁻¹ gives the identity matrix.

A A⁻¹ = A⁻¹ A = I

A matrix has an inverse if and only if it is non-singular, meaning its determinant is non-zero.

A⁻¹ = adj(A) / det(A), when det(A) ≠ 0

Inverse of a 2 × 2 Matrix

For the matrix below:

A = [ a  b ]
   [ c  d ]
A⁻¹ = 1/(ad − bc) [ d  -b ]
          [ -c  a ]

Solved Example 2

Find the inverse of:
A = [ 2  1 ]
   [ 1  1 ]

Step 1: Calculate determinant.

det(A) = (2 × 1) − (1 × 1) = 1

Step 2: Apply the inverse formula.

A⁻¹ = [ 1  -1 ]
     [ -1  2 ]

Since det(A) = 1 ≠ 0, the inverse exists.

3. Rank of a Matrix

The rank of a matrix is the maximum number of linearly independent rows or columns. It is also equal to the number of non-zero rows in its row echelon form.

rank(A) = Number of non-zero rows in REF

The rank cannot exceed the number of rows or columns.

rank(A) ≤ min(m, n)

Solved Example 3

Find the rank of:
A = [ 1  2  3 ]
   [ 2  4  6 ]
   [ 1  1  1 ]
Apply R₂ → R₂ − 2R₁ and R₃ → R₃ − R₁.
[ 1  2  3 ]
[ 0  0  0 ]
[ 0  -1  -2 ]
After arranging the non-zero rows:
[ 1  2  3 ]
[ 0  -1  -2 ]
[ 0  0  0 ]

There are two non-zero rows.

rank(A) = 2

4. Systems of Linear Equations

A system of linear equations consists of two or more linear equations involving unknown variables. In matrix form:

AX = B

Here:

  • A = coefficient matrix
  • X = column matrix of unknowns
  • B = column matrix of constants

4.1 Consistency Conditions

Let A be the coefficient matrix and [A|B] the augmented matrix.

rank(A) = rank([A|B])
The system is consistent.
rank(A) ≠ rank([A|B])
The system is inconsistent and has no solution.

For a consistent system with n unknowns:

  • If rank(A) = n, the solution is unique.
  • If rank(A) < n, infinitely many solutions exist.

Solved Example 4: Unique solution

Solve:
x + y = 5
x − y = 1
Adding both equations:
2x = 6 ⇒ x = 3
Substitute x = 3 into x + y = 5:
3 + y = 5 ⇒ y = 2

Answer: x = 3, y = 2.

Solved Example 5: Inconsistent system

Consider:
x + y = 2
x + y = 5
Subtracting the first equation from the second gives:
0 = 3

This is impossible. Therefore, the system has no solution and is inconsistent.

5. Eigenvalues and Eigenvectors

An eigenvector of a square matrix A is a non-zero vector X whose direction remains unchanged when A acts on it. The corresponding eigenvalue λ describes the scaling factor.

AX = λX

Rearranging:

(A − λI)X = 0

For a non-zero solution X to exist, the determinant must be zero.

det(A − λI) = 0
This is the characteristic equation.

Solved Example 6

Find the eigenvalues of:
A = [ 2  0 ]
   [ 0  3 ]

Step 1: Form the characteristic equation.

det(A − λI) = 0
(2 − λ)(3 − λ) = 0

Step 2: Solve.

λ₁ = 2, λ₂ = 3

Step 3: Find eigenvectors.

For λ = 2, solving (A − 2I)X = 0 gives an eigenvector:
X₁ = [ 1 ]
    [ 0 ]
For λ = 3:
X₂ = [ 0 ]
    [ 1 ]

6. Diagonalization of a Matrix

Diagonalization means expressing a square matrix in the form A = PDP⁻¹, where D is a diagonal matrix and P is formed from linearly independent eigenvectors of A.

A = PDP⁻¹

The diagonal entries of D are the eigenvalues. The columns of P are the corresponding eigenvectors, arranged in the same order.

A matrix of order n is diagonalizable if it has n linearly independent eigenvectors. Having n distinct eigenvalues is a sufficient condition for diagonalizability, but it is not necessary.

Solved Example 7

For the matrix:
A = [ 2  0 ]
   [ 0  3 ]
The eigenvectors form the columns of:
P = [ 1  0 ]
   [ 0  1 ]
The diagonal matrix is:
D = [ 2  0 ]
   [ 0  3 ]
Since P = I, we have:
A = PDP⁻¹ = D

This matrix is already diagonal, so diagonalization is immediate.

7. Cayley–Hamilton Theorem

The Cayley–Hamilton theorem states that every square matrix satisfies its own characteristic equation.

If the characteristic polynomial of A is:

p(λ) = det(λI − A)

and

p(λ) = λⁿ + c₁λⁿ⁻¹ + ... + cₙ

then the theorem gives:

p(A) = Aⁿ + c₁Aⁿ⁻¹ + ... + cₙI = 0

We replace every power of λ in the characteristic polynomial with the corresponding power of A.

Solved Example 8

Let:
A = [ 2  0 ]
   [ 0  3 ]

Step 1: Find the characteristic polynomial.

det(λI − A) = (λ − 2)(λ − 3)
p(λ) = λ² − 5λ + 6

Step 2: Apply Cayley–Hamilton.

A² − 5A + 6I = 0

This verifies the theorem because A is diagonal with entries 2 and 3, and each satisfies λ² − 5λ + 6 = 0.

8. Important Formula Revision

Inverse:
A⁻¹ = adj(A) / det(A), provided det(A) ≠ 0
Rank:
rank(A) = Number of non-zero rows in REF
Consistency:
rank(A) = rank([A|B])
Eigenvalues:
det(A − λI) = 0
Eigenvectors:
(A − λI)X = 0, where X ≠ 0
Diagonalization:
A = PDP⁻¹
Cayley–Hamilton:
p(A) = 0

9. Common Exam Mistakes

  • Always use elementary operations correctly while reducing a matrix.
  • Do not confuse row echelon form with reduced row echelon form.
  • Check det(A) ≠ 0 before using the inverse formula.
  • For consistency, compare the ranks of A and its augmented matrix.
  • Eigenvectors must be non-zero vectors.
  • In diagonalization, keep eigenvectors and eigenvalues in matching column and diagonal positions.
  • In the Cayley–Hamilton theorem, substitute A for λ throughout the characteristic polynomial.
