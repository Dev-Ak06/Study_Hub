1. Double Integrals

What is a Double Integral?

A double integral is used to integrate a function of two variables over a two-dimensional region. It can be used to calculate the volume under a surface.

Notation

∬R f(x,y) dA

Here, R represents the region of integration and dA represents a small area element.

Types of Double Integrals

  • Type I: Integration with respect to y first.
  • Type II: Integration with respect to x first.

Solved Example 1

Evaluate:

∫₀¹ ∫₀² (x + y) dy dx

Step 1: Integrate with respect to y

∫₀² (x + y) dy

= [xy + y²/2]₀²

= 2x + 2

Step 2: Integrate the result with respect to x

∫₀¹ (2x + 2) dx

= [x² + 2x]₀¹

= 1 + 2 = 3

Answer: 3

2. Triple Integrals

What is a Triple Integral?

A triple integral integrates a function of three variables over a three-dimensional region.

It is useful for finding the volume of a solid and, in suitable applications, its mass.

Notation

∭V f(x,y,z) dV

Solved Example 2

Evaluate:

∫₀¹ ∫₀¹ ∫₀¹ 1 dz dy dx

Step 1: Integrate with respect to z

∫₀¹ 1 dz = [z]₀¹ = 1

Step 2: Integrate with respect to y

∫₀¹ 1 dy = 1

Step 3: Integrate with respect to x

∫₀¹ 1 dx = 1

Answer: 1 cubic unit

This result represents the volume of a unit cube.

3. Change of Order of Integration

Simple Explanation

Changing the order of integration means changing the sequence of integration variables and adjusting the limits to describe the same region.

For example, an integral written as dy dx may sometimes be rewritten as dx dy.

Important Rule

You must first understand and draw the region of integration. Then determine the new limits from the same region.

Solved Example 3

Evaluate:

∫₀¹ ∫₀ˣ 1 dy dx

Step 1: Understand the limits

The limits indicate:

  • 0 ≤ x ≤ 1
  • 0 ≤ y ≤ x

This is the triangular region below y = x, above y = 0, and between x = 0 and x = 1.

Step 2: Reverse the order

When integrating with respect to x first:

0 ≤ y ≤ 1, and y ≤ x ≤ 1

The new integral is:

∫₀¹ ∫ᵧ¹ 1 dx dy

Step 3: Evaluate the original integral

∫₀¹ [y]₀ˣ dx = ∫₀¹ x dx

= [x²/2]₀¹ = 1/2

Step 4: Check the reversed integral

∫₀¹ [x]ᵧ¹ dy = ∫₀¹ (1 - y) dy

= [y - y²/2]₀¹ = 1/2

Answer: 1/2

Both orders give the same answer because the integration region remains unchanged.

4. Line Integrals

Simple Explanation

A line integral integrates a function along a curve or path.

It is used in applications such as calculating work done by a force along a path.

Scalar Line Integral

∫C f(x,y) ds

Here, C is the curve and ds is a small length element along that curve.

Solved Example 4

Evaluate ∫C x ds along the straight line from (0,0) to (1,0).

Step 1: Parametrize the line

Let x = t and y = 0, where 0 ≤ t ≤ 1.

Step 2: Calculate ds

ds = √((dx/dt)² + (dy/dt)²) dt

Since dx/dt = 1 and dy/dt = 0:

ds = dt

Step 3: Substitute into the integral

∫₀¹ t dt = [t²/2]₀¹

Answer: 1/2

5. Surface Integrals

Simple Explanation

A surface integral integrates a scalar function or a vector field over a surface in three-dimensional space.

A scalar surface integral can be written as:

∬S f(x,y,z) dS

A vector surface integral is often used to calculate flux through a surface.

Solved Example 5

Evaluate ∬S 1 dS for a rectangle in the xy-plane with 0 ≤ x ≤ 2 and 0 ≤ y ≤ 3.

Step 1: Identify the surface

The rectangle lies in the xy-plane, so dS = dx dy.

Step 2: Set up the integral

∫₀² ∫₀³ 1 dy dx

Step 3: Evaluate

∫₀² [y]₀³ dx = ∫₀² 3 dx

= [3x]₀² = 6

Answer: 6 square units

6. Volume Integrals

Simple Explanation

Volume integrals integrate a function throughout a three-dimensional region.

When the integrand is 1, a triple integral calculates the volume of the region.

Solved Example 6

Find the volume of the rectangular solid:

0 ≤ x ≤ 2, 0 ≤ y ≤ 3, 0 ≤ z ≤ 4

Step 1: Set up the triple integral

V = ∫₀² ∫₀³ ∫₀⁴ 1 dz dy dx

Step 2: Integrate with respect to z

∫₀⁴ 1 dz = 4

Step 3: Integrate with respect to y

∫₀³ 4 dy = 12

Step 4: Integrate with respect to x

∫₀² 12 dx = 24

Answer: 24 cubic units

7. Change of Variables

Simple Explanation

Change of variables replaces the original variables with new variables to make an integral easier to evaluate.

In double integrals, changing from x,y to u,v requires a Jacobian factor.

Jacobian Formula

dx dy = |∂(x,y)/∂(u,v)| du dv

The absolute value of the Jacobian is used in the area element.

Common Polar Coordinate Formulas

  • x = r cos θ
  • y = r sin θ
  • x² + y² = r²
  • dA = r dr dθ

Solved Example 7

Evaluate:

∬R (x² + y²) dA

where R is the unit disk x² + y² ≤ 1.

Step 1: Change to polar coordinates

x² + y² = r² and dA = r dr dθ.

The limits are 0 ≤ r ≤ 1 and 0 ≤ θ ≤ 2π.

Step 2: Write the new integral

∫₀²π ∫₀¹ r³ dr dθ

Step 3: Integrate with respect to r

∫₀¹ r³ dr = [r⁴/4]₀¹ = 1/4

Step 4: Integrate with respect to θ

∫₀²π (1/4) dθ = π/2

Answer: π/2

Practice Questions

  1. Evaluate ∫₀¹ ∫₀² (2x + y) dy dx.
  2. Evaluate ∫₀¹ ∫₀ˣ y dy dx.
  3. Evaluate ∫₀¹ ∫₀¹ ∫₀² 1 dz dy dx.
  4. Evaluate ∫C y ds along the line from (0,0) to (0,2).
  5. Find the area of the rectangle 0 ≤ x ≤ 4, 0 ≤ y ≤ 5 using a double integral.
  6. Convert x² + y² into polar coordinates and state the area element dA.
  7. Evaluate ∬R (x² + y²) dA over the unit disk using polar coordinates.

Module 4: Quick Revision

  • Double integrals: integration over a 2D region.
  • Triple integrals: integration over a 3D region.
  • Change of order: adjust limits to preserve the region.
  • Line integrals: integration along a curve.
  • Surface integrals: integration over a surface.
  • Volume integrals: integration throughout a solid.
  • Change of variables: transform variables and include the Jacobian.
