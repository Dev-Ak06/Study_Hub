1. Functions of Several Variables

Simple Explanation

A function of several variables is a function that depends on two or more independent variables.

For example, z = x² + y² depends on both x and y. Here, x and y are independent variables, and z is the dependent variable.

Solved Example

Find z when x = 2 and y = 3.

Given: z = x² + y²

Step 1: Substitute x = 2 and y = 3.

z = 2² + 3²

Step 2: Calculate the squares.

z = 4 + 9 = 13

Answer: z = 13

2. Limit and Continuity

Limit

A limit describes the value a function approaches when its variables approach particular values.

For a function f(x,y), we may write: lim (x,y)→(a,b) f(x,y).

Solved Example

Evaluate the limit of f(x,y) = x² + y² as (x,y) approaches (1,2).

Step 1: Substitute x = 1 and y = 2.

1² + 2² = 1 + 4 = 5

Answer: 5

Continuity

A function is continuous at a point if its limit exists there and equals the function's value at that point.

For two-variable functions, we must check the limit carefully. Direct substitution alone is not sufficient for every function.

3. Differentiability

Simple Explanation

Differentiability describes whether a function has a well-defined local rate of change.

For functions of several variables, differentiability is stronger than merely having partial derivatives.

If the first partial derivatives exist and are continuous near a point, that is a sufficient condition for differentiability at that point.

Important Note

The existence of partial derivatives at a single point does not by itself guarantee differentiability.

4. Partial Derivatives

Simple Explanation

A partial derivative measures how a function changes with respect to one variable while keeping the other variables constant.

Notation

For z = f(x,y):

  • ∂z/∂x means differentiate with respect to x.
  • ∂z/∂y means differentiate with respect to y.

Solved Example

Find both partial derivatives of:

z = x²y + 3xy²

Step 1: Differentiate with respect to x

Treat y as a constant.

∂z/∂x = 2xy + 3y²

Step 2: Differentiate with respect to y

Treat x as a constant.

∂z/∂y = x² + 6xy

Answers:

∂z/∂x = 2xy + 3y²

∂z/∂y = x² + 6xy

5. Total Derivatives and Applications

Simple Explanation

A total derivative measures the overall change in a function when its independent variables also change.

If z = f(x,y), where x and y depend on t, then:

dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt)

Solved Example

Given z = x² + y², x = t and y = 2t.

Step 1: Find the partial derivatives.

∂z/∂x = 2x

∂z/∂y = 2y

Step 2: Find the derivatives of x and y.

dx/dt = 1 and dy/dt = 2

Step 3: Apply the total derivative formula.

dz/dt = (2x)(1) + (2y)(2)

Substitute x = t and y = 2t:

dz/dt = 2t + 8t = 10t

Answer: dz/dt = 10t

6. Chain Rule

Simple Explanation

The chain rule is used when one variable depends on other variables that themselves depend on another variable.

If z = f(x,y), and x and y depend on t:

dz/dt = (∂z/∂x)(dx/dt) + (∂z/∂y)(dy/dt)

Solved Example

Given z = xy, x = t² and y = 3t.

Step 1: Find the partial derivatives.

∂z/∂x = y and ∂z/∂y = x

Step 2: Find dx/dt and dy/dt.

dx/dt = 2t and dy/dt = 3

Step 3: Apply the chain rule.

dz/dt = y(2t) + x(3)

Substitute x = t² and y = 3t.

dz/dt = (3t)(2t) + (t²)(3)

dz/dt = 6t² + 3t² = 9t²

Answer: dz/dt = 9t²

7. Implicit Functions

Simple Explanation

An implicit function is represented by an equation in which the dependent variable is not necessarily written alone.

Example: x² + y² = 25

Solved Example

Find dy/dx for x² + y² = 25.

Step 1: Differentiate both sides with respect to x.

2x + 2y(dy/dx) = 0

Step 2: Move 2x to the right side.

2y(dy/dx) = -2x

Step 3: Divide by 2y.

Answer: dy/dx = -x/y, where y ≠ 0.

8. Euler's Theorem for Homogeneous Functions

Simple Explanation

A homogeneous function has terms of the same total degree.

For example, x² + xy + y² is homogeneous of degree 2.

Euler's Theorem

If z = f(x,y) is differentiable and homogeneous of degree n, then:

x(∂z/∂x) + y(∂z/∂y) = nz

Solved Example

Verify Euler's theorem for z = x² + xy + y².

Step 1: The function has degree 2, so n = 2.

Step 2: Find the partial derivatives.

∂z/∂x = 2x + y

∂z/∂y = x + 2y

Step 3: Substitute into the left-hand side.

x(2x + y) + y(x + 2y)

= 2x² + xy + xy + 2y²

= 2x² + 2xy + 2y²

Step 4: Compare with 2z.

2z = 2(x² + xy + y²)

Both sides are equal. Therefore, Euler's theorem is verified.

9. Jacobian

Simple Explanation

A Jacobian is a determinant made from partial derivatives. It is useful in changing variables and studying how transformations affect space.

If u = u(x,y) and v = v(x,y), then:

∂(u,v)/∂(x,y) = (∂u/∂x)(∂v/∂y) - (∂u/∂y)(∂v/∂x)

Solved Example

Given u = x + y and v = x - y, find the Jacobian.

Step 1: Find the partial derivatives.

∂u/∂x = 1, ∂u/∂y = 1

∂v/∂x = 1, ∂v/∂y = -1

Step 2: Apply the formula.

J = (1)(-1) - (1)(1)

J = -1 - 1 = -2

Answer: J = -2

10. Maxima and Minima of Two-Variable Functions

Simple Explanation

A maximum is a point where a function has a local high value. A minimum is a point where it has a local low value.

Steps to Find Stationary Points

  1. Find ∂f/∂x and ∂f/∂y.
  2. Set both partial derivatives equal to zero.
  3. Solve the equations to find stationary points.
  4. Use the second derivative test to classify them.

Second Derivative Test

Calculate D = fxx fyy - (fxy)².

  • If D > 0 and fxx > 0: local minimum.
  • If D > 0 and fxx < 0: local maximum.
  • If D < 0: saddle point.
  • If D = 0: the test is inconclusive.

Solved Example

Find the minimum of f(x,y) = x² + y² - 4x - 6y.

Step 1: Find the first partial derivatives.

fx = 2x - 4 = 0, so x = 2.

fy = 2y - 6 = 0, so y = 3.

Step 2: Find the second partial derivatives.

fxx = 2, fyy = 2, fxy = 0.

Step 3: Calculate D.

D = (2)(2) - 0² = 4.

Since D > 0 and fxx > 0, the point (2,3) is a local minimum.

Step 4: Calculate the minimum value.

f(2,3) = 4 + 9 - 8 - 18 = -13

Answer: Minimum value = -13 at (2,3).
